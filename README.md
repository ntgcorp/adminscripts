## 💾 1. Partition Backup/Restore: `admin_partclone_backup.sh` / `admin_partclone_restore.sh`

Smart partition backup using `partclone` + `gzip` that backs up only used data blocks (skips free space), compresses on the fly.

**Backup usage:**
```bash
sudo ./admin_partclone_backup.sh <source_partition> <destination_folder> <compression_level_1-9>
sudo ./admin_partclone_backup.sh /dev/sda1 /mnt/usb_storage 6
```

**Restore usage:**
```bash
sudo ./admin_partclone_restore.sh <compressed_backup_file> <target_partition>
sudo ./admin_partclone_restore.sh /mnt/usb/backup/backup_ntfs_sda1_20260609_193000.img.gz /dev/sda1
```

**Key features:**
- Compression levels 1–9 (6 recommended balance)
- Auto-detects filesystem (ntfs, ext4, fat32, etc.)
- Output naming: `backup_[FSTYPE]_[PARTITION]_[YYYYMMDD_HHMMSS].img.gz`
- Restore requires typing `SI` (uppercase) confirmation
- Italian messages, English technical output

> Full regeneration prompt: `Prompt/prompt_admin_partclone.md`

## 💿 2. Full Disk Imaging: `admin_disk_image.sh` / `admin_disk_restore.sh`

Complete disk imaging via `dd | pv | gzip` (backup) and `gunzip | pv | dd` (restore). Captures partition table, boot sectors, all partitions.

**Backup usage:**
```bash
sudo ./admin_disk_image.sh <source_disk> <dest_folder> <base_name>
sudo ./admin_disk_image.sh /dev/sda /mnt/backup server_disk
```

**Restore usage:**
```bash
sudo ./admin_disk_restore.sh <image_file> <target_disk>
sudo ./admin_disk_restore.sh /mnt/backup/server_disk_20260802120000.img.gz /dev/sdb
```

**Key features:**
- Auto-installs `pv` via `apt` if missing (Debian/Ubuntu live)
- Log file in same folder as output image (backup) or source image (restore)
- Output naming: `<base_name>_<YYYYMMDDHHMMSS>.img.gz`
- Restore: 5-second cancel window, mounted-target check
- Phased ANSI-colored console output

> Full regeneration prompts: `Prompt/prompt_admin_disk_image.md`, `Prompt/prompt_admin_disk_restore.md`

## 🌐 3. NAS Mounting: `admin_nas_mount.sh`

Mount SMB, NFS, or FTP shares to `/mnt/<folder>` with automatic mount-point creation (755 perms).

**Usage:**
```bash
# SMB (3 params)
./admin_nas_mount.sh smb ntgdsnas temp
# NFS (3 params)
./admin_nas_mount.sh nfs 192.168.1.100 backup
# FTP (5 params)
./admin_nas_mount.sh ftp ftp.example.com data user pass
```

**Key features:**
- SMB: guest or credential auth, CIFS vers=3.0
- NFS: assumes `/volume1/<folder>` export path
- FTP: via `curlftpfs` (FUSE), requires `curlftpfs` package
- Auto-creates `/mnt/<folder>` if missing
- Prevents duplicate mounts

> Full regeneration prompt: `Prompt/prompt_admin_nas_mount.md`

## 📊 6. Folder Size Analysis: `admin_folders_size.sh`

Lists first-level subfolder sizes in descending order with MB filter.

**Usage:**
```bash
./admin_folders_size.sh <start_folder> <mbfilter>
./admin_folders_size.sh /home/user/data 100
./admin_folders_size.sh / 100   # Special case: scans predefined system dirs
```

**Special case `/`:** Scans only these existing dirs (excludes `/mnt`):
`/bin /etc /lib /lost+found /proc /run /snap /tmp /var /boot /home /lib64 /media /opt /root /sbin /srv /sys /usr`

**Output:** Formatted table `SIZE | FOLDER` sorted descending.

> Full regeneration prompt: `Prompt/prompt_admin_folders_size.md`

## 🔄 7. System Migration: `admin_migrate.sh`

Backup/restore for Zorin OS / Ubuntu / Debian. Handles APT packages, Flatpak, Snap, all `/home/*`, and system settings (`/etc`, `dconf`).

**Usage:**
```bash
./admin_migrate.sh backup /mnt/backup/destination
./admin_migrate.sh restore /mnt/backup/source
```

**Structure created:**
```
<target>/
├── 1_apt/          package.list, manual_packages.txt, sources.list*
├── 2_flatpak/      flatpak_apps.txt
├── 3_snap/         snap_apps.txt
├── 4_home/         rsync backup of /home/*
├── 5_settings/     dconf_desktop_settings.ini, fstab, hosts, environment
```

**Key features:**
- Phased logging with timestamps (INFO/WARN/ERROR)
- Resilient: individual failures logged as warnings, script continues
- rsync for home directories with cache/trash exclusions
- Log file: `<target>/migrate_<action>.log`

> Full regeneration prompt: `Prompt/prompt_admin_migrate.md`

## 🌐 9. Selenium Drivers: `selenium_driver_download.ps1` / `.cmd` / `ps_start.cmd`

Downloads SeleniumBasic (COM library) and ChromeDriver to target folder (default `C:\seleniumbasic`).

**Usage:**
```cmd
selenium_driver_download.cmd
```

## 💾 13. Creating a Bootable USB (GParted Live)

1. Download GParted Live ISO (amd64) from official site.
2. In Rufus: Device=USB, Boot=ISO, Partition=MBR, FS=exFAT.
3. Flash (ISO Image mode).
4. Create `ntjobs/` folder on USB root, copy all `.sh`, `.ps1`, `.py`, `.cmd` files there.

## 🖥️ 14. Running in Live Environment

```bash
cd /lib/live/mount/medium/ntjobs/   # or /run/live/medium/ntjobs/
chmod +x *.sh
sudo ./your_script.sh
```
